# 背景音乐清单：每行一首，按顺序循环播放。以 # 开头的行是注释，不会播放。
#
# 两种写法（可以混用）：
#   1. music/ 文件夹里的音频文件名（mp3 / m4a / aac / wav）——可以离线播放
#        晨钟.mp3  晨钟
#   2. YouTube 链接（单个视频或播放列表都可以）——需要联网
#        https://www.youtube.com/watch?v=视频ID  曲名
#        https://www.youtube.com/playlist?list=列表ID  我的列表
#
# 链接或文件名后面空一格可以写曲名（可省略）。
